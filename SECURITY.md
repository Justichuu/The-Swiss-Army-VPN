# Security

Never post VPN credentials in an issue, commit, screenshot, GIF, film, or release.

Widget-state stills are rendered with `--preview-state`. They show the packaged default server name only. Do not commit a live window that has a username, password, or home path in it.

Report security problems privately through GitHub's security-advisory feature. Include the app version and the exact Windows error, but remove usernames, passwords, IP addresses, and personal paths.
