# Swiss Army VPN

Uma página. Se ler só uma coisa, leia esta.

## O que é

Uma janela pequena do Windows para uma VPN que o Windows já sabe usar. Também pode cortar o resto da internet se essa VPN cair. Esse corte chama-se kill switch (bloqueio).

Não é a empresa NordVPN. Não é um serviço novo. Você traz o login.

## O que faz no computador

- Cria uma VPN do Windows chamada Swiss Army VPN.
- Pode ligar quatro regras de firewall que cortam a internet normal.
- Pode guardar utilizador e palavra-passe. O Windows fica com elas.
- Pode mudar o servidor.

Não lê os seus ficheiros. Não guarda sites. Não guarda o token do GitHub.

## O que não faz

Não corre WireGuard nem OpenVPN.

Não o torna seguro sozinho numa rede má. O bloqueio só ajuda se estiver ligado e o túnel for o que a app vigia.

## Começar

1. Descarregue o zip da última Release no GitHub. Não use o botão verde Code.
2. Abra a pasta. Mantenha os ficheiros juntos.
3. Execute `Install Swiss Army VPN.exe`. O Windows pede administrador.
4. Abra a app. SET UP SIGN-IN. Escreva o login da sua VPN.
5. CONNECT + ARM se quiser o bloqueio. CONNECT se não.

## Parar

DISCONNECT + UNLOCK.

Se a janela não abrir e não houver internet: Emergency Unlock no menu Iniciar.

## Se ficar preso

O bloqueio pode cortar o computador inteiro. Primeiro desbloqueie.

Não envie um registo cru. Passe pelo scrubber antes de partilhar.

## Privacidade

As palavras-passe ficam no Windows. Sem cara, sem voz, sem jogo com tempo.

Problema de segurança: GitHub security advisories. Nunca uma palavra-passe num issue.
