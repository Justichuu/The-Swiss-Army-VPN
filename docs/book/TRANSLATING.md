# Translating

Write like a person talking to a neighbour. Short sentences. No tool names. No “utilise.”

## What to copy

Start with `en/PAMPHLET.md`. Then `en/START.md` if you have time.

Keep the same headings, in the same order. A reader who switches language should not get lost.

## Rules

- Do not translate file names of the app (`Install Swiss Army VPN.exe`).
- Do not translate colour hex values.
- Do not add a CAPTCHA or a timed quiz to “prove you read it.”
- Do not write “as an AI.”
- If a word has no clean match, keep the English and add one plain word next to it. Example: kill switch (lock).

## How to add a folder

```text
docs/book/<code>/PAMPHLET.md
```

Use a short language code: `es`, `fr`, `pl`, `ko`, `ar`. Right-to-left is welcome. Say so at the top of the file.

Open a pull request. A docs correction counts.

## Access

A translation can arrive as typed text, a voice note written down later, or a support worker’s words. There is no timer.
