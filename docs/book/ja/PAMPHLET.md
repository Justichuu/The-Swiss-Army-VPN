# Swiss Army VPN

1枚です。一つだけ読むならこれです。

## これは何か

Windows がもともと使える VPN のための、小さな窓です。その VPN が切れたとき、残りのネットを止められます。その止めを kill switch（ロック）と呼びます。

NordVPN 社ではありません。新しい VPN サービスでもありません。ログインは自分で用意します。

## コンピュータにすること

- Swiss Army VPN という Windows の VPN を一つ足します。
- 普通のネットを止めるファイアウォール規則を四つ付けられます。
- ユーザー名とパスワードを保存できます。保管は Windows です。
- サーバを変えられます。

ファイルは読みません。見たサイトは残しません。GitHub のトークンは持ちません。

## しないこと

WireGuard も OpenVPN も動かしません。

悪いネットを、これだけで安全にはしません。ロックが入り、このアプリが見ているトンネルのときだけ役立ちます。

## 始め方

1. GitHub の最新 Release から zip を取る。緑の Code は使わない。
2. フォルダを開く。中身はばらさない。
3. `Install Swiss Army VPN.exe` を実行する。管理者の許可が出る。
4. アプリを開く。SET UP SIGN-IN。自分の VPN のログインを入れる。
5. ロックが要るなら CONNECT + ARM。要らないなら CONNECT。

## 止め方

DISCONNECT + UNLOCK。

窓が開かずネットも死んでいるときは、スタートの Emergency Unlock。

## 困ったとき

ロックはコンピュータ全体を止められます。それが目的です。先に解除する。

生のログは送らない。共有する前にスクラバーを通す。

## プライバシー

パスワードは Windows に残ります。顔も声も制限時間付きのテストも求めません。

安全の報告は GitHub の security advisories。Issue にパスワードを書かない。
